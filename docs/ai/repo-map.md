## How to use

Run `npm run repo-map:generate` after edits to routes, repositories, ownership playbooks or skills, and commit both generated files. `npm run repo-map:check` and Jest reject stale output. The JSON also lists each module’s literal Supabase table/view and RPC references.

This index is **not** the database access-control inventory. Check migrations and `docs/rls-verification-checklist.md` before changing sensitive code.
