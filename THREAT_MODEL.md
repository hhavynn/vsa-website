# VSA website threat model

**Scope:** Production VSA website and its Supabase, Vercel and GitHub workflow boundaries. This is a public repository; never put credentials, private student data, attack instructions or actual check-in values here.

Review this document when adding a new feature or changing a trust boundary, **in the same PR**. Mark a control **unverified** unless a focused test or deployed verification proves it. Browser checks and client validation are UX, not authorization.
